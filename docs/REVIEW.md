# 最新版本审查

审查覆盖采集脚本、轮转/保留、时间回溯、离线火焰图、systemd 模板、测试、Skill、对话导出与交付打包。

## 已修复

1. perf script 改为显式输出进程 PID 等字段，避免默认线程标识导致过滤漏样本；仅对相同 IP/符号的重复头部叶帧去重，保留真实递归。
2. 解码超时/资源限制标记 UNINDEXED，保留原文件并支持 reindex；不再误判 CORRUPT。快速退出时也检查 stdout/stderr 总容量，stderr 有界读取；解码启动失败也清理临时文件。
3. 未知样本时间的损坏/空/未索引分片按完成时间保留，避免时间 0 导致立即清理；跨 boot 淘汰按墙上时间，减少反复全目录扫描。
4. 恢复检查关联 boot ID，避免系统重启后 PID/start ticks 巧合被误判孤儿 perf；活跃文件描述符不可检查时不发布分片。
5. perf 启动失败更新 FAILED 会话；结束阶段保证文件句柄、信号处理器和数据库释放；NaN/Inf 等采集时长在附着前拒绝。
6. systemd 改为 KillMode=mixed，先由监督进程通知 perf 封口；增加私有 StateDirectory 与环境配置示例，补全安装和停止验收文档，并修正专用用户读取配置的权限。
7. 合成查询复用预算内快照，取消多余复制。真实 Linux 测试通过 readiness gate 在采集就绪后才启动热点，避免环境检查耗时消耗热点窗口。
8. 完整演示脚本显式使用项目目录启动子进程，可从其他工作目录运行；移除工具目录中遗留的失败演示产物，并补端到端回归。
9. 打包只接受干净、已提交源文件，写入 Git revision 与完整历史 bundle，临时 ZIP 校验后发布。
10. 修复窄分支缩放改变 SVG 比例导致的图高/字体增大。固定 viewBox，重新计算选中路径内的横向坐标，保留祖先/子路径并隐藏无关路径；增加单路径说明、可读时间、样本详情及故障/基线/完整时段对比。指定 Skill 的分析流程在合成数据上执行，没有替换为未经验证的 Linux 引擎。
